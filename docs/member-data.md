# 위스키 렌즈 — 회원 데이터 정의

2026-10-27 기준. 회원정보는 **서버 DB**(MongoDB Atlas 무료 등급, 데이터베이스 `whiskylens`, 컬렉션 `members`)에 저장하고 어드민(`/admin/members`)에서 관리한다.
다만 실제 소셜 로그인과 휴대폰 본인인증은 아직 없다(**시연용 가입**) — 가입하면 서버가 그 기기에 열쇠(token)를 하나 주고, 기기는 그 열쇠로 자기 회원정보를 읽고 고친다(DB 에는 열쇠의 해시만).
로그인 방식과 19세 인증 업체가 정해지면 그 부분만 바꾼다. 화면(시작하기 · 가입 · 회원정보 · 내 레시피 프로필)은 그대로 둔다.

## 화면

| 주소 | 화면 | 하는 일 |
|---|---|---|
| `/login` | 시작하기 | 가입 방법 고르기(카카오 · 네이버 · Google · 이메일), 둘러보기 |
| `/signup` | 가입 3단계 | ① 약관 동의 → ② 만 19세 확인 → ③ 닉네임 · 프로필 색 · 취향 |
| `/account` | 회원정보 | 프로필 고치기, 이벤트·혜택 알림 켜고 끄기, 연결된 계정 · 약관 동의일, 로그아웃 · 탈퇴 |
| `/me` 위 | 내 프로필 | 닉네임 · 취향 요약 · 내 기록(저장한 레시피 · 보낸 레시피 · 만들어 본 것) |

## 회원 한 명(`member`)

| 칸 | 모양 | 필수 | 뜻 |
|---|---|---|---|
| `id` | 문자 | ○ | 회원 번호 |
| `provider` | `kakao` · `naver` · `google` · `email` | ○ | 가입 방법 |
| `nickname` | 2~12자 | ○ | 화면에 부르는 이름. 레시피를 보낼 때 "○○님의 레시피"로 붙는다 |
| `avatar` | 색 이름(`highball` · `lemon` · `cola` · `tonic` · `ginger` · `earlgrey`) | ○ | 프로필 원 색 |
| `birthYear` | 네 자리 수 | ○ | 태어난 해 — 나이 확인용. 서버에서는 본인인증 결과로 바꾼다 |
| `adultVerified` | 참/거짓 | ○ | 만 19세 이상 확인 여부 |
| `verifiedBy` | `demo` · `phone` | ○ | 확인 방법. 지금은 `demo`(태어난 해만 받음) |
| `verifiedAt` | 시각 | ○ | 확인한 때 |
| `agreements.terms` | 시각 | ○ | 서비스 이용약관 동의한 때 |
| `agreements.privacy` | 시각 | ○ | 개인정보 수집·이용 동의한 때 |
| `agreements.adult` | 시각 | ○ | "만 19세 이상" 확인 동의한 때 |
| `consentVersions.terms` · `consentVersions.privacy` | 판 번호 · 없음 | ○ | 가입할 때 시행 중이던 이용약관 · 개인정보처리방침 판(어드민 '사업자 정보·약관'). 약관이 바뀌면 다시 묻는 기준 |
| `agreements.marketing` | 시각 · 없음 | | 이벤트·혜택 알림 동의(없으면 받지 않음). 회원정보에서 켜고 끈다 |
| `taste.moods` | 맛 목록(깔끔 · 상큼 · 달콤 · 향긋 · 알싸 · 쌉쌀) | | 좋아하는 맛 — 추천에 쓴다 |
| `taste.strength` | 2 · 3 · 4 | | 좋아하는 농도(진하게 1:2 · 보통 1:3 · 연하게 1:4) |
| `status` | `active` · `suspended` | ○ | 이용 중 · 이용 정지(어드민이 정한다 — 정지된 회원은 회원정보를 고칠 수 없다) |
| `tokenHash` | 문자 | ○ | 그 기기 열쇠의 해시(밖으로 내보내지 않는다) |
| `createdAt` · `updatedAt` · `lastSeenAt` | 시각 | ○ | 가입한 때 · 마지막으로 고친 때 · 마지막 접속 |

## 이용 기록(`activity`) — 어드민 대시보드의 숫자

| 칸 | 뜻 |
|---|---|
| `type` | `save`(레시피 저장) · `send`(레시피 보내기) · `made`(만드는 과정을 끝까지 봄) |
| `recipeKey` · `whiskyId` | 어떤 레시피를, 어떤 위스키로 |
| `memberId` | 회원이면 회원 번호(비회원은 없음) — 개인정보는 담지 않는다 |
| `at` | 한 때 |

## 아직 기기에만 있는 것(회원 번호로 서버에 묶는 것은 다음 단계)

| 이름 | 자리 | 내용 |
|---|---|---|
| 내 레시피 | `wl.saved` | 레시피 · 위스키 · 비율(칵테일은 맛 조절) · 양 · 붙인 이름 · 메모 · 보낸 사람 |
| 내 바 | `wl.bar` | 가진 믹서 · 맛 더하기 · 칵테일 재료 · 위스키 |
| 내 기록 | `wl.stats` | 보낸 레시피 수(`sent`) · 만드는 과정을 끝까지 본 수(`made`) |

## 지켜야 할 것

- **만 19세 이상만** 쓴다(청소년보호법). "청소년"은 만 19세 미만이되 만 19세가 되는 해의 1월 1일을 맞은 사람은 빼므로, **태어난 해로 가른다**(올해 − 태어난 해 ≥ 19). 실제 서비스는 휴대폰 본인인증(PASS 등)으로 확인한다 — 건당 비용이 드는 유료 서비스라 업체를 정해야 한다.
- 개인정보는 **필요한 것만** 받는다. 이름 · 휴대폰 번호 · 생년월일 같은 본인인증 결과는 나이 확인에만 쓰고, 화면에는 닉네임만 쓴다.
- 이벤트·혜택 알림은 **선택** 동의다. 동의한 때를 남기고, 언제든 끌 수 있어야 한다.
- 탈퇴하면 회원정보를 지운다(회원 스스로 · 어드민 탈퇴 처리 모두). 이용 기록에는 회원 번호만 남아 누구인지 알 수 없다.
- 약관 · 개인정보 처리방침 본문은 클라이언트가 정해 "보기"에 연결한다.

## 실제 서비스로 갈 때 할 일

1. 로그인 방식 정하기 — 카카오 로그인이 가장 흔하다(연령대 정보도 받을 수 있지만 19세 확인은 본인인증이 확실하다). 정해지면 provider 계정 번호로 같은 회원을 찾게 하고, 기기 열쇠를 로그인 세션으로 갈음한다.
2. 본인인증 업체 정하기(건당 비용). `verifiedBy` 가 `phone` 이 된다.
3. 내 레시피 · 내 바도 회원 번호로 서버에 묶기(`lib/saved.js`). 이 기기에 남은 기록은 첫 로그인 때 서버로 옮겨 준다.
4. 공유 2단계(모두의 레시피 · "나도 만들었어요" · 위스키별 사람들 비율 통계)를 회원 위에 올린다.
5. 무료 등급 한도: Atlas 무료 클러스터는 저장 공간 512MB(보틀 렌즈와 함께 쓴다). 회원·이용 기록이 많아지면 유료 등급이나 기록 보관 기간을 정한다.
